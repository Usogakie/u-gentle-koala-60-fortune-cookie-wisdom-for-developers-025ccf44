One original fortune-cookie line for a software developer, written by a small deterministic Python program. The line: your future self is already debugging the shortcut you are about to take. It reads like a fortune cookie, says something true about a developer's day — shortcuts, debugging, the future self who pays for them — and lands its quiet twist on the second read: the future is already at work before you have even taken the shortcut.

## Run it

```sh
python3 main.py
```
